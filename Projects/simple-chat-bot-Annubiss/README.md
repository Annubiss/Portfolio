# Simple-Chat-Bot
Get to know the basic syntax of JavaScript and write a simple program using variables, conditions, loops, and functions.

## About
Here, at the beginning of your Javascript path, creating a simple console chat bot will do wonders to guide you through the basics of coding. During this journey you will also play some word and number games that you are going to implement all on your own.
