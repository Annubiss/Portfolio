# Amazing-Prices
Improve your HTML and CSS skills by creating a page layout from the ready-made designs. Moreover, practice CSS Flexbox and learn about HTML5 Tables. In the end, make your page responsive for different screen sizes.

## About
You have developed an outstanding service for your users. Now, it’s time to show the prices with a pricing page! In this project, you will design a page layout for the pricing of a service or a product. Practice your frontend skills using HTML & CSS and build a page based on our designs.
